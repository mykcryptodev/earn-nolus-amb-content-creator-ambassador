## About Nolus (Context)

Nolus is a cross-chain DeFi protocol for **spot margin trading** built on a **lease-based leverage model**. Key points covered throughout this submission:

- **DeFi Lease** — Up to 150% financing on initial capital; users hold real underlying tokens
- **Fixed protocol interest** — Predictable borrowing costs for the full position lifecycle
- **Risk controls** — Partial liquidations, EMA oracle pricing, MAG safeguards
- **IBC interoperability** — Cross-chain connectivity without traditional bridge trust assumptions
- **Connected liquidity hubs** — Osmosis DEX; Solana (Metis API) coming soon
- **Audited** — Oak Security + Halborn; active bug bounty

**Official links:** [Website](https://nolus.io/) · [dApp](https://app.nolus.io/leases) · [Knowledge Hub](https://hub.nolus.io/en/) · [Discord](https://discord.com/invite/nolus-protocol)
